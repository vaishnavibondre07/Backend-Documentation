# HTTP vs HTTPS

# What is HTTP?

HTTP stands for:

```text
HyperText Transfer Protocol
```

It is used for communication between:
- Browser
- Server

---

# What is HTTPS?

HTTPS stands for:

```text
HyperText Transfer Protocol Secure
```

HTTPS is secure version of HTTP.

---

# Main Difference

## HTTP

Data transferred in plain text.

## HTTPS

Data encrypted and secure.

---

# Why HTTPS is Important

Without HTTPS:
- Passwords can be stolen
- Data can be intercepted
- Hackers can read information

HTTPS prevents this.

---

# Example

## HTTP

```text
http://example.com
```

## HTTPS

```text
https://example.com
```

---

# SSL/TLS

HTTPS uses:
- SSL
- TLS

for encryption.

---

# What is Encryption?

Encryption converts readable data into unreadable format.

Only authorized systems can decrypt it.

---

# How HTTPS Works

# Step 1

Browser connects to server.

# Step 2

Server sends SSL certificate.

# Step 3

Browser verifies certificate.

# Step 4

Encrypted connection established.

---

# Advantages of HTTPS

## 1. Secure Data

Protects passwords and tokens.

## 2. Better SEO

Google prefers HTTPS websites.

## 3. Builds Trust

Shows lock icon in browser.

## 4. Prevents Data Theft

Encrypted communication.

---

# Disadvantages of HTTP

- Not secure
- Vulnerable to attacks
- Unsafe for authentication

---
