# Client Server Architecture

# What is Client Server Architecture?

Client Server Architecture is a system where:

- Client sends request
- Server processes request
- Server sends response

This is the foundation of backend development.

---

# Real Life Example

Imagine ordering food online.

## Client

You use a mobile app or website.

Example:
- Browser
- Mobile App
- Frontend Application

You request:

"Give me pizza details"

## Server

The backend server receives request.

It:
- Processes request
- Gets data from database
- Sends response back

---

# Simple Flow

```text
Client  --->  Server  ---> Database
   <--- Response <---
```

---

# Who is Client?

Client is anything that requests data.

Examples:
- Chrome Browser
- Mobile Apps
- React Frontend
- Postman

---

# Who is Server?

Server is software or machine that provides data/services.

Examples:
- Node.js Server
- Express Server
- Apache
- Nginx

---

# How It Works

## Step 1 — User Sends Request

Example:

```http
GET /users
```

Browser sends request to backend.

---

## Step 2 — Server Receives Request

Backend receives request.

Example:

```js
app.get("/users", (req, res) => {
   res.send("Users Data")
})
```

---

## Step 3 — Server Processes Logic

Server may:
- Validate user
- Check authentication
- Fetch database data
- Perform calculations

---

## Step 4 — Database Communication

Server talks to database.

Example:
- MongoDB
- MySQL
- PostgreSQL

---

## Step 5 — Response Sent Back

Server sends response.

Example:

```json
{
   "success": true,
   "data": []
}
```

---

# Why Client Server Architecture is Important

Because it:
- Separates frontend and backend
- Makes systems scalable
- Makes maintenance easier
- Improves security

---

# Advantages

## 1. Better Security

Database hidden from client.

## 2. Scalability

Can handle many users.

## 3. Centralized Data

All data managed at one place.

## 4. Easy Maintenance

Frontend and backend can change independently.

---

# Disadvantages

## 1. Server Dependency

If server crashes, system stops.

## 2. Expensive Infrastructure

Large systems need powerful servers.

## 3. Network Dependency

Internet required.

---

# Types of Client Server Architecture

## 1-Tier Architecture

Everything in one system.

Example:
- Simple desktop applications

---

## 2-Tier Architecture

Client directly talks to database.

```text
Client ---> Database
```

---

## 3-Tier Architecture

Most common.

```text
Frontend ---> Backend ---> Database
```

---

# Real Example in Node.js

```js
const express = require("express")

const app = express()

app.get("/", (req, res) => {
   res.send("Hello World")
})

app.listen(3000)
```

Browser acts as client.

Node.js acts as server.

# Important Terms

## Request

Message sent by client.

## Response

Data returned by server.

## API

Way for client and server to communicate.

## Endpoint

Specific route.

Example:

```http
/api/users
```

# Interview Questions

---

# Summary

Client Server Architecture is the backbone of web development.

Frontend communicates with backend server.
Backend processes requests and communicates with database.
Server returns response to client.
