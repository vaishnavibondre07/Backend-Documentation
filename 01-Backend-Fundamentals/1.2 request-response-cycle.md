# Request Response Cycle

# What is Request Response Cycle?

Request Response Cycle is the complete process of:

1. Client sends request
2. Server processes request
3. Server sends response

Every website works on this cycle.

---

# Simple Diagram

```text
Client ---> Request ---> Server
Client <--- Response <--- Server
```

---

# Example

You open:

```text
https://google.com
```

Browser sends request.

Google server sends webpage response.

---

# Step By Step Working

# Step 1 — User Action

User:
- Clicks button
- Opens website
- Submits form

---

# Step 2 — Request Sent

Browser sends HTTP request.

Example:

```http
GET /products
```

---

# Step 3 — Server Receives Request

Backend receives request.

Example:

```js
app.get("/products", (req, res) => {})
```

---

# Step 4 — Middleware Runs

Middleware may:
- Check authentication
- Validate request
- Log request

---

# Step 5 — Business Logic Runs

Server:
- Fetches database data
- Processes calculations
- Performs operations

---

# Step 6 — Database Communication

Backend communicates with database.

---

# Step 7 — Response Generated

Server creates response.

Example:

```json
{
   "products": []
}
```

---

# Step 8 — Response Sent

Client receives response.

Browser displays data.

---

# Types of HTTP Requests

## GET

Fetch data.

## POST

Create data.

## PUT

Update entire data.

## PATCH

Update partial data.

## DELETE

Delete data.

---

# Example Request

```http
POST /register
```

---

# Example Response

```json
{
   "success": true,
   "message": "Registered Successfully"
}
```

---

# Important Parts of Request

## URL

Endpoint path.

## Method

GET, POST etc.

## Headers

Additional information.

## Body

Actual data sent.

---

# Important Parts of Response

## Status Code

Example:
- 200 OK
- 404 Not Found

## Headers

Response information.

## Body

Actual response data.

---

# Status Code Categories

| Code | Meaning |
|---|---|
| 2xx | Success |
| 3xx | Redirection |
| 4xx | Client Error |
| 5xx | Server Error |

---

# Example in Express.js

```js
app.post("/login", (req, res) => {

   const email = req.body.email

   res.status(200).json({
      success: true
   })
})
```

# Why Request Response Cycle is Important

Because every backend API works on it.

Understanding this helps in:
- API development
- Debugging
- Authentication
- Error handling

---

# Common Errors

## 404 Error

Route not found.

## 500 Error

Internal server error.

## 401 Error

Unauthorized access.

The complete process of request and response communication between client and server.

## What happens before response is sent?

Middleware, business logic, and database operations run.
