# package.json in Node.js

# What is package.json?

package.json is the most important file in any Node.js project.

It contains:

```text
Project metadata + dependencies + scripts
```

---

# Simple Definition

```text
package.json = Configuration file for Node.js project
```

---

# Why package.json is Important

It helps to:
- Manage dependencies
- Run scripts
- Store project info
- Maintain versioning

---

# How to Create package.json

```bash
npm init
```

OR (fast way):

```bash
npm init -y
```

---

# Example package.json

```json
{
  "name": "my-app",
  "version": "1.0.0",
  "description": "Node.js backend project",
  "main": "index.js",
  "scripts": {
    "start": "node index.js"
  },
  "author": "Vaishnavi",
  "license": "ISC"
}
```

---

# Important Fields

## 1. name

Project name.

```json
"name": "backend-api"
```

---

## 2. version

Project version.

```json
"version": "1.0.0"
```

---

## 3. description

Short project description.

---

## 4. main

Entry file of project.

```json
"main": "index.js"
```

---

## 5. scripts

Custom commands.

```json
"scripts": {
  "start": "node index.js",
  "dev": "nodemon index.js"
}
```

---

# Running Scripts

```bash
npm start
```

OR

```bash
npm run dev
```

---

# 6. dependencies

Libraries required in production.

Example:

```json
"dependencies": {
  "express": "^4.18.0"
}
```

---

```bash

```

---

# 7. devDependencies

# What is npm install doing?

When you run:

```bash
npm install express
```

It:
- Downloads package
- Adds to node_modules
- Updates package.json
- Creates package-lock.json

---

# What is package-lock.json?

It locks exact dependency versions.

```text
Ensures same environment for everyone
```

---

# Semantic Versioning (IMPORTANT)

```text
MAJOR.MINOR.PATCH
```

Example:

```text
1.2.3
```

---

## MAJOR (1.x.x)
Breaking changes

---

## MINOR (x.2.x)
New features

---

## PATCH (x.x.3)
Bug fixes

---

# Version Symbols

## ^ (Caret)

```json
"express": "^4.18.0"
```

Allows minor updates.

---

## ~ (Tilde)

```json
"express": "~4.18.0"
```

Allows only patch updates.

---

# package.json vs package-lock.json

| package.json | package-lock.json |
|---|---|
| User-defined | Auto-generated |
| Flexible versions | Fixed versions |
| Editable | Not edited manually |

---
