# Event Driven Model in Node.js

# What is Event Driven Model?

Event Driven Model is a programming pattern where:

```text
Execution of code depends on events (actions)
```

In Node.js, everything is based on events.

---

# Simple Definition

```text
Event Driven Model = System reacts to events instead of running step-by-step code
```

---

# What is an Event?

An event is something that happens.

Examples:
- User clicks button
- Server receives request
- File upload completes
- Timer finishes

---

# Real Life Example

Think about a doorbell:

```text
Someone presses bell → You react
```

You don’t keep checking the door every second.

---

# How Node.js Uses Events

Node.js uses:
- Event Emitter
- Callbacks
- Event Loop

---

# Basic Flow

```text
Event Occurs → Listener Detects → Callback Executes
```

---

# Event Emitter Concept

Node.js has built-in module:

```js
events
```

It allows:
- Creating events
- Listening to events
- Triggering events

---

# Simple Event Example

```js
const EventEmitter = require("events")

const emitter = new EventEmitter()

emitter.on("greet", () => {
   console.log("Hello User!")
})

emitter.emit("greet")
```

---

# Output

```text
Hello User!
```

---

# Explanation

## on()

Registers event listener.

## emit()

Triggers event.

---

# Real Backend Example

```js
emitter.on("userRegistered", (user) => {
   console.log("Send Email to", user)
})

emitter.emit("userRegistered", "Vaishnavi")
```

---

# Output

```text
Send Email to Vaishnavi
```

---

# Why Event Driven Model is Powerful

Because:
- No continuous checking
- Efficient resource usage
- Handles many users simultaneously

---

# Event Driven Architecture in Node.js

```text
Client Request
      ↓
Event Triggered
      ↓
Event Loop
      ↓
Callback Executes
```

---

# Components of Event Driven Model

## 1. Events

Actions or occurrences.

---

## 2. Event Emitter

Object that emits events.

---

## 3. Event Listener

Function that waits for event.

---

## 4. Callback

Function executed when event happens.

---

# Synchronous vs Event Driven

## Synchronous

```text
Step 1 → Step 2 → Step 3
```

---

## Event Driven

```text
Event → React → Execute
```

---

# Node.js Server Example

```js
const http = require("http")

const server = http.createServer((req, res) => {

   if (req.url === "/") {
      res.end("Home Page")
   }

   if (req.url === "/about") {
      res.end("About Page")
   }
})

server.listen(3000)
```

---

# What is Happening?

Each request is an event:
- "/" event
- "/about" event

Node.js reacts accordingly.

---

# Why Node.js Uses Event Driven Model

Because it helps:
- Handle many requests
- Avoid blocking
- Improve performance

---

# Event Loop + Event Driven Model

They work together:

- Event Driven = What to do
- Event Loop = When to do it

---

# Advantages

## 1. Efficient

No unnecessary waiting.

---

## 2. Scalable

Handles many users.

---

## 3. Fast Response

Immediate reaction to events.

---

## 4. Non-blocking

Main thread is never blocked.

---

# Disadvantages

## 1. Complex Debugging

Many events can be hard to track.

---

## 2. Callback Overuse

Can lead to messy code.

---

## 3. Hard for Beginners

Requires async understanding.
