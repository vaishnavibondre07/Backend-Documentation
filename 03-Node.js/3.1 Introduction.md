# Node.js Introduction

# What is Node.js?

Node.js is a runtime environment that allows JavaScript to run outside the browser.

It is used to build:
- Backend servers
- APIs
- Real-time applications
- Scalable network applications

---

# Simple Definition

```text
Node.js = JavaScript runtime for server-side development
```

---

# What is a Runtime?

A runtime is an environment where code executes.

Example:
- Browser runs JavaScript
- Node.js runs JavaScript on server

---

# Node.js is Built On

Node.js is built using:

- Chrome V8 JavaScript Engine
- C++
- libuv (for async I/O)

---

# Why Node.js Exists?

Before Node.js:
- JavaScript only worked in browsers
- Backend was only Java, PHP, Python

Now:
- Same language (JavaScript) for frontend + backend

---

# Node.js Architecture

Node.js uses:

## 1. Single Threaded Model
One main thread handles all requests.

## 2. Event Driven Model
Uses events to handle operations.

## 3. Non-blocking I/O
Does not wait for tasks to finish.

---

# Simple Flow

```text
Request → Event Loop → Async Operation → Response
```

---

# Why Node.js is Fast?

Because:
- It does NOT wait for I/O operations
- Uses event loop
- Uses async processing

---

# Node.js Features

## 1. Fast Execution
Powered by V8 engine.

## 2. Asynchronous
Non-blocking architecture.

## 3. Scalable
Handles many requests.

## 4. Single Language
Frontend + backend JavaScript.

## 5. Open Source
Free and widely supported.

# Node.js vs Browser JavaScript

| Feature | Browser | Node.js |
|---|---|---|
| Runs in | Browser | Server |
| Access DOM | Yes | No |
| File System | No | Yes |
| APIs | Web APIs | Node APIs |

# Node.js Execution Process

1. Write code
2. Run using node command
3. V8 engine compiles JS
4. Event loop handles async tasks
5. Output returned

# Node.js Advantages

- High performance
- Fast development
- Large ecosystem (npm)
- Real-time support

---

# Node.js Disadvantages

- Not good for CPU-heavy tasks
- Callback complexity (without async/await)
- Less suitable for heavy computation systems
