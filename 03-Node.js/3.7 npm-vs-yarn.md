# npm vs Yarn in Node.js

# What are npm and Yarn?

Both npm and Yarn are package managers used in Node.js.

They are used to:
```text
Install, manage, and update dependencies
```

---

# What is npm?

npm = Node Package Manager

It comes pre-installed with Node.js.

---

# What is Yarn?

Yarn is an alternative package manager created by Facebook.

It was built to solve some npm performance issues (older versions).

---

# Simple Definition

```text
npm = default Node.js package manager
Yarn = faster alternative package manager
```

---

# What do they do?

Both:
- Install packages
- Manage dependencies
- Run scripts
- Handle package.json

---

# Basic Commands Comparison

## Install dependency

### npm
```bash
npm install express
```

### Yarn
```bash
yarn add express
```

---

## Install all dependencies

### npm
```bash
npm install
```

### Yarn
```bash
yarn install
```

---

## Remove package

### npm
```bash
npm uninstall express
```

### Yarn
```bash
yarn remove express
```

---

## Run scripts

### npm
```bash
npm run start
```

### Yarn
```bash
yarn start
```

---

# Speed Comparison

## npm
- Slower in older versions
- Improved in npm 7+

## Yarn
- Faster installation (parallel downloads)

---

# Lock Files

## npm
```text
package-lock.json
```

## Yarn
```text
yarn.lock
```

---

# Why Lock Files are Important

They ensure:
```text
Same dependencies across all environments
```

---

# Key Differences

| Feature | npm | Yarn |
|---|---|---|
| Default with Node | Yes | No |
| Speed | Good (new versions) | Very fast |
| Lock file | package-lock.json | yarn.lock |
| Offline install | Limited | Better support |
| Stability | High | High |

---

---

---

# Why Yarn was Created

Earlier npm had issues:
- Slow installs
- No lock file initially
- Inconsistent dependency tree

Yarn solved:
- Faster installs
- Deterministic installs
- Better caching

---

# How Yarn is Faster

Because:
- Parallel package downloads
- Better caching system
- Efficient dependency resolution

---

# npm Improvements (Modern)

Now npm includes:
- Faster installs
- Lock file support
- Better caching

So difference is smaller now.

---

# Which One Should You Use?

## Recommended:

```text
Use npm (modern projects)
```

Because:
- Default with Node.js
- Widely used
- Industry standard

---

## Use Yarn if:

- Existing project uses Yarn
- You want faster installs
- Team prefers Yarn
