# Node.js Architecture

# What is Node.js Architecture?

Node.js architecture defines how Node.js internally handles:
- Requests
- Asynchronous tasks
- Event handling
- Execution flow

It is designed for:
```text
High performance + Non-blocking I/O + Scalability
```

---

# Core Idea of Node.js Architecture

Node.js follows:

## 1. Single Threaded Model
One main thread handles all requests.

## 2. Event Driven Architecture
Everything works based on events.

## 3. Non-blocking I/O
Operations do NOT block execution.

---

# Node.js Architecture Diagram (Simple)

```text
Client Request
      ↓
   Node.js Server
      ↓
 Event Queue
      ↓
 Event Loop
      ↓
 Worker Threads (libuv)
      ↓
 Response to Client
```

---

# Main Components

## 1. V8 Engine
- Executes JavaScript code
- Converts JS → machine code
- Very fast execution

---

## 2. Libuv

Libuv handles:
- Thread pool
- File system operations
- Async tasks
- Event loop

---

## 3. Event Loop

Heart of Node.js.

It:
- Picks tasks
- Executes callbacks
- Manages async flow

---

## 4. Callback Queue

Stores:
- Completed async tasks
- Ready-to-execute callbacks

---

## 5. Thread Pool

Used for heavy operations like:
- File system
- Encryption
- DNS lookup

(Default size = 4 threads)

---

# How Node.js Handles a Request

## Step 1 — Request Comes In

Client sends request:

```http
GET /users
```

---

## Step 2 — Goes to Event Loop

Event loop receives request.

---

## Step 3 — Check Operation Type

### If NON-BLOCKING (e.g. API call)
Handled directly by event loop.

### If BLOCKING (e.g. file system)
Sent to thread pool.

---

## Step 4 — Worker Thread Executes Task

Thread pool processes task.

---

## Step 5 — Callback Returned

Result sent to callback queue.

---

## Step 6 — Event Loop Executes Callback

Response sent back to client.

---

# Why Node.js is Fast

Because:
- It never waits for I/O
- Uses async processing
- Uses event loop efficiently

---

# Blocking vs Non-Blocking

## Blocking

```js
const data = fs.readFileSync("file.txt")
```

Stops execution.

---

## Non-Blocking

```js
fs.readFile("file.txt", (err, data) => {
   console.log(data)
})
```

Does NOT block execution.

---

# Event Loop Role in Architecture

Event loop:
- Continuously runs
- Checks callback queue
- Executes tasks when stack is free

---

# Thread Pool Usage

Used for:
- File operations
- Crypto operations
- Compression
- DNS lookup

---

# Advantages of Node.js Architecture

## 1. High Scalability

Handles many users easily.

---

## 2. Fast Performance

No blocking operations.

---

## 3. Efficient Resource Usage

Uses fewer threads.

---

## 4. Suitable for Real-Time Apps

Chat, streaming, APIs.

---

# Disadvantages

## 1. Not good for CPU-heavy tasks

Example:
- Machine learning
- Heavy computations

---

## 2. Complex Async Flow

Without async/await, code becomes complex.
