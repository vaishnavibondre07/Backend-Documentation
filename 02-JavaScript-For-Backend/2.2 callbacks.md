# Callbacks in JavaScript

# What is Callback?

Callback is a function passed into another function as an argument.

It is executed later.

---

# Simple Definition

```text
Function passed as argument to another function.
```

---

# Basic Example

```js
function greet(name, callback) {

   console.log("Hello " + name)

   callback()
}

function done() {
   console.log("Completed")
}

greet("Vaishnavi", done)
```

---

# Output

```text
Hello Vaishnavi
Completed
```

---

# Why Callbacks are Needed

JavaScript is:
- Single threaded
- Asynchronous

Callbacks help handle async operations.

---

# Real World Example

Imagine ordering food.

```text
Order food
↓
Wait for cooking
↓
Food ready notification
```

Callback works similarly.

---

# Asynchronous Callback Example

```js
console.log("Start")

setTimeout(() => {
   console.log("Inside Callback")
}, 2000)

console.log("End")
```

---

# Output

```text
Start
End
Inside Callback
```

---

# Why?

`setTimeout()` is asynchronous.

Callback runs later.

---

# Callback Flow

```text
Main Code Executes
↓
Async Task Starts
↓
Main Thread Continues
↓
Callback Executes Later
```

---

# Common Backend Example

# Reading File

```js
const fs = require("fs")

fs.readFile("test.txt", "utf-8", (err, data) => {

   if (err) {
      console.log(err)
      return
   }

   console.log(data)
})
```

---

# Callback Parameters

Usually:

```js
(error, result)
```

---

# Error First Callback Pattern

Node.js commonly uses:

```js
(err, data)
```

---

# Why Error First?

Because async operations may fail.

Example:
- File missing
- Database error
- API failure

---

# Callback Hell

Nested callbacks create messy code.

---

# Example

```js
loginUser(() => {

   getProfile(() => {

      getPosts(() => {

         getComments(() => {

         })

      })

   })

})
```

---

# Problem

This becomes:
- Hard to read
- Hard to debug
- Hard to maintain

---

# Callback Hell Pyramid

```text
Callback
   Callback
      Callback
         Callback
```

---

# Solution

Modern JavaScript uses:
- Promises
- Async/Await

---

# Callback in Express.js

Middleware uses callbacks.

```js
app.use((req, res, next) => {

   console.log("Middleware")

   next()
})
```

`next()` is callback.

---

# Advantages of Callbacks

# 1. Async Programming

Helps non-blocking operations.

---

# 2. Fast Execution

Does not stop main thread.

---

# 3. Event Handling

Useful in events.

---

# Disadvantages of Callbacks

# 1. Callback Hell

Nested callbacks become messy.

---

# 2. Hard Error Handling

Complex nested error handling.

---

# 3. Difficult Maintenance

Large callback chains difficult to manage.

---

# Callback vs Promise

| Callback | Promise |
|---|---|
| Old approach | Modern approach |
| Nested | Cleaner |
| Hard error handling | Better handling |
