# Promises in JavaScript

# What is Promise?

Promise is an object representing future completion or failure of an asynchronous operation.

---

# Simple Definition

```text
Promise is a placeholder for future value.
```

---

# Why Promises Were Introduced

To solve:
- Callback hell
- Complex async code
- Difficult error handling

---

# Real Life Example

Ordering food online.

```text
Order Placed
↓
Food Preparing
↓
Delivered OR Failed
```

Promise works similarly.

---

# Promise States

# 1. Pending

Initial state.

Operation still running.

---

# 2. Fulfilled

Operation successful.

---

# 3. Rejected

Operation failed.

---

# Promise Lifecycle

```text
Pending
   ↓
Fulfilled OR Rejected
```

---

# Creating Promise

```js
const promise = new Promise((resolve, reject) => {

   let success = true

   if (success) {
      resolve("Success")
   } else {
      reject("Failed")
   }
})
```

---

# Consuming Promise

```js
promise
   .then((data) => {
      console.log(data)
   })
   .catch((error) => {
      console.log(error)
   })
```

---

# Output

```text
Success
```

---

# resolve()

Used when operation succeeds.

---

# reject()

Used when operation fails.

---

# then()

Handles successful result.

---

# catch()

Handles errors.

---

# finally()

Runs always.

Example:
- Cleanup operations
- Closing database connection

---

# Example with finally

```js
promise
   .then(() => {})
   .catch(() => {})
   .finally(() => {
      console.log("Done")
   })
```

---

# Promise Example Using setTimeout

```js
const task = new Promise((resolve, reject) => {

   setTimeout(() => {
      resolve("Task Completed")
   }, 2000)
})

task.then((data) => {
   console.log(data)
})
```

---

# Promise Chaining

```js
Promise.resolve(10)

   .then((data) => {
      return data * 2
   })

   .then((data) => {
      return data + 5
   })

   .then((data) => {
      console.log(data)
   })
```

---

# Output

```text
25
```

---

# Why Chaining is Useful

Avoids callback hell.

Makes code cleaner.

---

# Promise Error Handling

```js
fetchData()

   .then((data) => {
      console.log(data)
   })

   .catch((err) => {
      console.log(err)
   })
```

---

# Promise Methods

# Promise.all()

Runs multiple promises together.

```js
Promise.all([promise1, promise2])
```

Fails if any promise fails.

---

# Promise.race()

Returns first completed promise.

---

# Promise.any()

Returns first successful promise.

---

# Promise.allSettled()

Returns all results.

Even failed ones.

---

# Backend Example

# Database Query

```js
function getUsers() {

   return new Promise((resolve, reject) => {

      resolve(["User1", "User2"])
   })
}

getUsers()
   .then((users) => {
      console.log(users)
   })
```

# Advantages of Promises

# 1. Cleaner Code

Better than callbacks.

---

# 2. Better Error Handling

Centralized error handling.

---

# 3. Promise Chaining

Readable async code.

---

# 4. Avoid Callback Hell

Flatten async logic.

---

# Disadvantages of Promises

# 1. Complex Chains Sometimes

Long chains can still become difficult.

---

# 2. Slightly Advanced for Beginners

Need understanding of async flow.

---

# Promise vs Callback

| Callback | Promise |
|---|---|
| Nested | Cleaner |
| Callback hell | Chaining |
| Hard errors | Better handling |

---

# Promise vs Async/Await

| Promise | Async/Await |
|---|---|
| Uses .then() | Cleaner syntax |
| More chaining | Looks synchronous |
