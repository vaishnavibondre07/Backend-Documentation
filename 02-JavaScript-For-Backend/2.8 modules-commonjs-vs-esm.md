# Modules in JavaScript (CommonJS vs ESM)

# What are Modules?

Modules help divide code into smaller reusable files.

Instead of writing everything in one file,
we split code into:
- Functions
- Classes
- Utilities
- Services

---

# Why Modules are Important

Without modules:
- Code becomes huge
- Hard to maintain
- Difficult debugging
- Poor scalability

Modules solve these problems.

---

# Simple Definition

```text
Module = Separate reusable piece of code.
```

---

# Example Without Modules

```js
// everything in one file
```

Large messy file.

---

# Example With Modules

```text
auth.js
database.js
server.js
utils.js
```

Cleaner structure.

---

# Types of Modules in JavaScript

# 1. CommonJS (CJS)

Traditional Node.js module system.

---

# 2. ECMAScript Modules (ESM)

Modern JavaScript module system.

---

# CommonJS (CJS)

Default in older Node.js.

Uses:
- require()
- module.exports

---

# Importing Module

```js
const math = require("./math")
```

---

# Exporting Module

```js
module.exports = {
   add,
   subtract
}
```

---

# Full CommonJS Example

# math.js

```js
function add(a, b) {
   return a + b
}

module.exports = add
```

---

# app.js

```js
const add = require("./math")

console.log(add(2, 3))
```

---

# Output

```text
5
```

---

# ESM (ECMAScript Modules)

Modern JavaScript module system.

Uses:
- import
- export

---

# Export Example

```js
export function add(a, b) {
   return a + b
}
```

---

# Import Example

```js
import { add } from "./math.js"
```

---

# Full ESM Example

# math.js

```js
export function add(a, b) {
   return a + b
}
```

---

# app.js

```js
import { add } from "./math.js"

console.log(add(2, 3))
```

---

# Output

```text
5
```

---

# Default Export in ESM

```js
export default function greet() {
   console.log("Hello")
}
```

Import:

```js
import greet from "./greet.js"
```

---

# Named Export

```js
export const name = "Node"
export const age = 20
```

Import:

```js
import { name, age } from "./data.js"
```

---

# CommonJS vs ESM

| CommonJS | ESM |
|---|---|
| require() | import |
| module.exports | export |
| Synchronous | Asynchronous |
| Older Node.js | Modern JavaScript |

---

# Why ESM is Modern Standard

Because:
- Supported in browsers
- Better optimization
- Better tree shaking
- Official JavaScript standard

---

# Enabling ESM in Node.js

Add in `package.json`

```json
{
   "type": "module"
}
```

---

# File Extensions in ESM

Need `.js`

```js
import data from "./data.js"
```
