# Closures in JavaScript

# What is Closure?

Closure is one of the most important concepts in JavaScript.

A closure happens when:

```text
A function remembers variables from its outer scope
even after the outer function has finished execution.
```

---

# Simple Definition

Closure means:

```text
Inner function can access outer function variables
even after outer function is completed.
```

---

# Why Closures Exist

Because JavaScript functions:
- Are first-class objects
- Remember lexical scope

---

# Basic Example

```js
function outer() {

   let count = 0

   function inner() {
      count++
      console.log(count)
   }

   return inner
}

const counter = outer()

counter()
counter()
counter()
```

---

# Output

```text
1
2
3
```

---

# What Happened Here?

# Step 1

`outer()` executes.

```js
let count = 0
```

created.

---

# Step 2

`inner()` returned.

```js
return inner
```

---

# Step 3

Normally outer function variables should disappear.

BUT...

JavaScript remembers `count`.

This is closure.

---

# Memory Visualization

```text
outer()
   ↓
count = 0
   ↓
inner() remembers count
```

---

# Closure Formula

```text
Function + Lexical Environment = Closure
```

---

# What is Lexical Scope?

Lexical scope means:

Function can access variables from:
- Its own scope
- Parent scope
- Global scope

---

# Example of Lexical Scope

```js
let globalVar = "Hello"

function outer() {

   let outerVar = "World"

   function inner() {
      console.log(globalVar)
      console.log(outerVar)
   }

   inner()
}

outer()
```

# Closures for Data Privacy

```js
function bankAccount() {

   let balance = 1000

   return {
      deposit(amount) {
         balance += amount
         console.log(balance)
      },

      getBalance() {
         return balance
      }
   }
}

const account = bankAccount()

account.deposit(500)

console.log(account.getBalance())
```

---

# Why This is Useful

`balance` cannot be directly modified.

Only accessible through functions.

This provides:
- Encapsulation
- Data protection

---

# Closures in setTimeout

```js
function test() {

   let name = "NodeJS"

   setTimeout(() => {
      console.log(name)
   }, 2000)
}

test()
```

Even after `test()` ends,
`name` is remembered.

---

# Common Interview Example

```js
for (var i = 1; i <= 3; i++) {

   setTimeout(() => {
      console.log(i)
   }, 1000)
}
```

---

# Output

```text
4
4
4
```

---

# Why?

Because:
- `var` has function scope
- Same variable shared

---

# Solution Using Closure

```js
for (let i = 1; i <= 3; i++) {

   setTimeout(() => {
      console.log(i)
   }, 1000)
}
```

---

# Output

```text
1
2
3
```
