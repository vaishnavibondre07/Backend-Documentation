# Event Loop in JavaScript

# What is Event Loop?

Event Loop is one of the most important concepts in JavaScript and Node.js.

It allows JavaScript to perform:
- Asynchronous operations
- Non-blocking execution

even though JavaScript is single-threaded.

---

# Simple Definition

```text
Event Loop manages execution of asynchronous tasks.
```

---

# Why Event Loop Exists

JavaScript has:
- Single Call Stack
- Single Main Thread

Without Event Loop:
- Async tasks would block application

---

# Real Life Example

Restaurant waiter.

```text
Take order
↓
Send to kitchen
↓
Serve another customer
↓
Return when food ready
```

Event Loop works similarly.

---

# JavaScript Execution Components

# 1. Call Stack

Stores function execution.

---

# 2. Web APIs / Node APIs

Handle async operations.

Examples:
- setTimeout
- File system
- Database
- HTTP requests

---

# 3. Callback Queue

Stores completed async callbacks.

---

# 4. Event Loop

Moves callbacks to call stack.

---

# Event Loop Architecture

```text
Call Stack
    ↑
Event Loop
    ↑
Callback Queue
```

---

# How Event Loop Works

# Step 1

Function enters Call Stack.

---

# Step 2

Async task sent to Web APIs.

---

# Step 3

Main thread continues execution.

---

# Step 4

Completed callback enters Callback Queue.

---

# Step 5

Event Loop checks:
- Is Call Stack empty?

If yes:
- Push callback into Call Stack.

---

# Example

```js
console.log("Start")

setTimeout(() => {
   console.log("Timeout")
}, 0)

console.log("End")
```

---

# Output

```text
Start
End
Timeout
```

---

# Why?

Because:
- setTimeout is async
- Callback enters queue
- Runs only after call stack empty

---

# Call Stack Visualization

```text
console.log("Start")
↓
setTimeout()
↓
console.log("End")
↓
Timeout callback
```

---

# What is Non-Blocking?

Non-blocking means:

JavaScript continues executing other code
without waiting for async operations.

---

# Blocking Example

```js
while(true) {}
```

This blocks Event Loop completely.

---

# Microtask Queue

Higher priority queue.

Contains:
- Promise callbacks
- queueMicrotask()

---

# Priority Order

```text
1. Call Stack
2. Microtask Queue
3. Callback Queue
```

---

# Example with Promise

```js
console.log("Start")

Promise.resolve().then(() => {
   console.log("Promise")
})

console.log("End")
```

---

# Output

```text
Start
End
Promise
```

---

# Why Promise Runs Before setTimeout

Microtask Queue has higher priority.

---

# Example

```js
console.log("Start")

setTimeout(() => {
   console.log("Timeout")
}, 0)

Promise.resolve().then(() => {
   console.log("Promise")
})

console.log("End")
```

---

# Output

```text
Start
End
Promise
Timeout
```

# Event Loop in Node.js

Node.js Event Loop phases:
- Timers
- Pending callbacks
- Poll
- Check
- Close callbacks

---

# Why Event Loop is Important in Backend

Node.js handles:
- Thousands of requests
- Async database queries
- File operations
- API requests

using Event Loop.

---

# Advantages of Event Loop

# 1. Non-Blocking

Application stays responsive.

---

# 2. High Performance

Efficient async handling.

---

# 3. Scalability

Handles many users.

# Disadvantages
