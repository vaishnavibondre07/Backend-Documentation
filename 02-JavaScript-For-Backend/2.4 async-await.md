# Async Await in JavaScript

# What is Async Await?

Async Await is modern way to handle asynchronous operations in JavaScript.

It is built on top of Promises.

Async Await makes asynchronous code look like synchronous code.

---

# Why Async Await Was Introduced

Promises improved callbacks.

But promise chaining still became difficult in large applications.

Async Await makes code:
- Cleaner
- Easier to read
- Easier to debug

---

# Simple Definition

## async

Makes function return Promise.

## await

Waits for Promise to complete.

---

# Basic Syntax

```js
async function test() {

   const result = await promise

   console.log(result)
}
```

---

# Example Without Async Await

```js
fetchData()
   .then((data) => {
      console.log(data)
   })
   .catch((err) => {
      console.log(err)
   })
```

---

# Same Example Using Async Await

```js
async function getData() {

   try {

      const data = await fetchData()

      console.log(data)

   } catch (err) {

      console.log(err)
   }
}
```

---

# What Happens Internally?

```text
await pauses function execution
until Promise completes
```

But JavaScript main thread does NOT block.

---

# Async Function Always Returns Promise

```js
async function test() {
   return "Hello"
}

console.log(test())
```

---

# Output

```text
Promise { 'Hello' }
```

---

# Await Only Works Inside Async Function

Wrong:

```js
const data = await fetchData()
```

Correct:

```js
async function getData() {
   const data = await fetchData()
}
```

---

# Example with setTimeout

```js
function delay() {

   return new Promise((resolve) => {

      setTimeout(() => {
         resolve("Completed")
      }, 2000)

   })
}

async function run() {

   console.log("Start")

   const result = await delay()

   console.log(result)

   console.log("End")
}

run()
```

---

# Output

```text
Start
Completed
End
```

---

# Error Handling with Try Catch

```js
async function getUser() {

   try {

      const user = await fetchUser()

      console.log(user)

   } catch (err) {

      console.log("Error:", err)
   }
}
```

---

# Why Try Catch is Important

Async operations may fail:
- Database errors
- API failures
- Network issues

---

# Backend Example

# Fetching Database Data

```js
async function getUsers(req, res) {

   try {

      const users = await User.find()

      res.json(users)

   } catch (err) {

      res.status(500).json({
         message: "Server Error"
      })
   }
}
```

---

# Sequential Async Operations

```js
const user = await getUser()

const posts = await getPosts(user.id)

const comments = await getComments(posts[0].id)
```

Runs one after another.

---

# Parallel Execution

```js
const [users, posts] = await Promise.all([
   getUsers(),
   getPosts()
])
```

Faster because both run together.

---

# Why Async Await is Better

# 1. Cleaner Syntax

Looks like normal synchronous code.

---

# 2. Better Readability

Easy to understand.

---

# 3. Better Error Handling

Uses try-catch.

---

# 4. Avoids Callback Hell

No deep nesting.

---

# Common Mistakes

# Forgetting await

```js
const data = fetchData()
```

Returns Promise instead of actual data.

---

# Using await Outside Async

Invalid syntax.

---

# Blocking Multiple Awaits

Wrong:

```js
await task1()
await task2()
```

Sometimes Promise.all() better.

---

# Async Await vs Promise

| Promise | Async Await |
|---|---|
| .then() chaining | Cleaner syntax |
| More nested | Easier reading |
| Harder debugging | Easier debugging |

---

# Async Await vs Callback

| Callback | Async Await |
|---|---|
| Callback hell | Clean flow |
| Hard errors | try-catch |
| Complex | Simpler |

# Interview Questions

## What is async await?

Modern syntax for handling asynchronous operations using Promises.

---

## Does async function return Promise?

Yes.

---

## Why use await?

To pause function execution until Promise resolves.

---

## Can await block JavaScript thread?

No.

Only pauses current async function.
